Quick Start

Setup in under 30 seconds

Install from npm in seconds. Local Brain auto-detects installed editors and links MCP configurations automatically. 

# Install globally from npm (requires Node.js ≥ 22)
npm install -g local-brain-mcp

# Navigate to your project and initialize Local Brain
cd /path/to/your-repo
 local-brain init

# Auto-detects Claude Code, Cursor, Antigravity, Copilot, Windsurf & Zed

# Ingest high-signal Git history into your local SQLite memory
local-brain ingest --since "12 months ago" --commits 500

Pipeline

How Local Brain Works

A continuous three-step loop that extracts, persists, and ranks high-signal engineering context without bloat.

01 — LEARN Discovery

An AI agent discovers useful knowledge

During debugging or refactoring, an agent (e.g. Claude Code or Cursor) identifies an architectural decision, edge runtime bug, or team convention.

brain_learn({
  lesson: "Use jose instead of jsonwebtoken on edge runtime",
  category: "fix",
  agent: "claude-code"
})
02 — STORE Persistence

Local Brain persists locally with provenance

Local Brain evaluates signal quality, embeds the lesson into SQLite vector tables, and attaches Git metadata (branch, commit SHA, file scope, agent identity).

INSERT INTO memories (
  quality_score: 1.45,
  git_branch: "main",
  status: "active"
)
03 — RECALL Retrieval

Another coding agent retrieves it later

When another agent works on the same codebase, it recalls the knowledge in ~3 ms (p50 under our local benchmark conditions) with deterministic multi-factor scoring capped at 250 tokens.

brain_recall({ query: "jwt auth" })
→ Score: 0.94 | Tokens: 42/250
→ Validated by Antigravity
Protocol

Model Context Protocol Reference

Exposes 7 standards-compliant MCP tools with complete runtime annotations for idempotency, read-only guarantees, and safety hints.

brain_recall
Semantic multi-factor recall across all agent memories with strict 250-token budget cap.
brain_learn
Store lessons, architecture decisions, and rules with automatic quality scoring.
brain_validate
Confirm memory correctness to boost rank and record cross-agent validation.
brain_status
Inspect memory counts, active/stale breakdown, and multi-agent health telemetry.
brain_trace
Chronological file memory history and agent attribution timeline.
brain_forget
Deprecate or permanently delete specific memory records by ID or query.
brain_prune
Clean up stale or deprecated memories from the brain after major refactors.
Core Capabilities

Built for serious engineering teams

Engineered from first principles for fast local execution, strict token economics, and multi-agent coordination.

100% Local-First

Your memory stays on your device. Zero external cloud egress, zero foreign databases, and total privacy for proprietary codebases.

Git-Aware Provenance

Every stored memory retains repository root, branch name, commit SHA, file path, and authoring agent metadata with automatic git-diff invalidation.

Multi-Agent Consensus

Cross-agent validation boosts verified memories, while contradiction detection applies an automatic 0.60× penalty to outdated or conflicting guidance.

Embedded SQLite Vector Store

High-concurrency Write-Ahead Logging (WAL) ensures simultaneous agent read/write operations without lock collisions or server dependencies.

Security Guarantee

Your memory stays local

Local Brain is designed for privacy-conscious developers and sensitive codebases.

Zero Network Egress

All vector embeddings, search calculations, and SQLite operations occur entirely within your local Node.js process.

Project Isolation

Memory stores are scoped deterministically to your repository root. Different projects cannot leak context into one another.

No API Keys Required

Deterministic embedded vectors run offline without external LLM API keys, quotas, rate limits, or billing subscriptions.
